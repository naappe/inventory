# Publisher Studio v3 — Safe Upgrade Scope

The existing Publisher Studio v3 templates and visual design are the fixed foundation.

## Do not change

- NationChat template layout
- Editorial Interview template layout
- Breaking News template layout
- Statement template layout
- Quick, Studio, and Developer modes
- Existing image upload, pan, zoom, Fit, Fill, and Reset workflow
- Existing Thaana/RTL rendering
- Existing overlay, brightness, contrast, save/load, recent projects, and export workflow

## Remove only

- Brand Pack control
- Brand Name control
- Duplicate footer brand marks currently rendered at the lower left and lower right of the NationChat output

## Add incrementally

- Select the existing speaker text and quote text directly on the canvas
- Drag those text blocks freely without changing their initial template position
- Resize and rotate selected text blocks
- Font family, font size, weight, color, alignment, and line-height controls
- Undo and redo
- Layers for the existing image and text blocks
- Lock, hide, duplicate, reorder, and delete only for user-editable elements

The default template must look exactly as it does now until the user moves or edits an element.
